## Task 1: Fix Liquid Tilt Physics in Pour Animation

**Problem:** Liquid drains vertically like a straw instead of tilting realistically inside the container. The container rotates at `+tiltDeg` while the liquid rotates at `-tiltDeg * 1.5`, creating a -2.5x net rotation that over-tilts the liquid surface.

**Files:**
- Modify: `app/index.tsx` — `BeerFill` component (lines ~323-363) and physics constants (lines ~14-18)

**Step 1: Understand the current tilt math**

The container wrapper applies `transform: [{ rotate: tiltDeg }]` (line ~141). Inside, `BeerFill` applies `liquidRotation = -tiltDeg * 1.5` (line ~325). Since the liquid is a child of the rotated container, the net visual rotation of the liquid is `tiltDeg + (-tiltDeg * 1.5) = -0.5 * tiltDeg` relative to the world — meaning it barely counter-rotates. The issue is actually that the liquid surface is defined by a sharp gradient edge, not a proper angled surface that responds to fill level.

**Step 2: Rework BeerFill to use an angled clip approach**

Replace the current rotated-gradient technique with a proper liquid surface:
- The liquid surface should be a straight line that tilts proportional to phone tilt
- At high fill levels, the tilt should be constrained (liquid can't go above the rim)
- At low fill levels, the tilt should be more dramatic (less liquid = more slosh)
- The liquid body below the surface line stays filled

Rewrite `BeerFill` to:
1. Calculate `surfaceAngle` based on `smoothedTilt` and `fillLevel` — more tilt effect at lower fill
2. Use a clipping approach: render a full-width liquid rectangle, then overlay a rotated mask for the surface
3. The surface angle should be relative to the container (not the world), so it looks like liquid sloshing inside

```tsx
// New approach for BeerFill
const BeerFill = ({ fillLevel, tiltDeg, containerWidth, containerHeight }: {
  fillLevel: number;
  tiltDeg: number;
  containerWidth: number;
  containerHeight: number;
}) => {
  const fillHeight = fillLevel * (containerHeight - 20);
  // More dramatic tilt at lower fill levels
  const tiltScale = 1.0 + (1.0 - fillLevel) * 0.8;
  // Surface angle relative to container — counter-rotate against container's world rotation
  const surfaceAngle = -tiltDeg * tiltScale;
  // How much the surface rises/falls on each side due to tilt
  const riseAmount = Math.sin((surfaceAngle * Math.PI) / 180) * (containerWidth / 2);

  return (
    <View style={{
      position: 'absolute',
      bottom: 0,
      left: 0,
      right: 0,
      height: fillHeight + Math.abs(riseAmount) + 20,
      overflow: 'hidden',
    }}>
      {/* Rotated liquid body */}
      <View style={{
        position: 'absolute',
        bottom: 0,
        left: -50,
        right: -50,
        height: fillHeight + Math.abs(riseAmount) + 80,
        transform: [{ rotate: `${surfaceAngle}deg` }],
        transformOrigin: 'center bottom',
      }}>
        <LinearGradient
          colors={[colors.amberLight, colors.amber, colors.amberDark]}
          locations={[0, 0.3, 1]}
          style={{ flex: 1 }}
        />
      </View>
    </View>
  );
};
```

**Step 3: Update foam to follow the tilted surface**

The foam layer should sit on top of the tilted liquid surface, not at a fixed position:

```tsx
const FoamHead = ({ fillLevel, tiltDeg, containerWidth, containerHeight }: {
  fillLevel: number;
  tiltDeg: number;
  containerWidth: number;
  containerHeight: number;
}) => {
  const fillHeight = fillLevel * (containerHeight - 20);
  const tiltScale = 1.0 + (1.0 - fillLevel) * 0.8;
  const surfaceAngle = -tiltDeg * tiltScale;
  // Scale foam with remaining liquid — thin out as it empties
  const foamHeight = Math.max(4, 16 * fillLevel);

  return (
    <View style={{
      position: 'absolute',
      bottom: fillHeight - 4,
      left: -20,
      right: -20,
      height: foamHeight + 10,
      overflow: 'hidden',
      transform: [{ rotate: `${surfaceAngle}deg` }],
    }}>
      <LinearGradient
        colors={['#FFF8DC', '#FAEBD7', '#FFE4B5']}
        style={{ flex: 1, borderRadius: 4 }}
      />
    </View>
  );
};
```

## Task 2: Fix Bottle Container Shape

**Problem:** The bottle has 3 separate pieces (cap, neck, body) with no taper between neck and body. The neck is a straight 30px tube that abruptly meets a 90px body with a hemispherical top (45px border radius). Real bottles have a smooth flare from neck to body.

**Files:**
- Modify: `app/index.tsx` — bottle render section (lines ~424-454) and bottle styles (lines ~665-725)

**Step 1: Redesign bottle as a unified shape**

Replace the 3-piece approach with a single container that uses layered Views to create a smooth taper:

```tsx
// Bottle: unified shape with neck taper
const renderBottle = () => {
  const innerH = BTL_BODY_H - 6;
  const bodyFill = Math.min(fillLevel * 1.2, 1) * innerH;

  return (
    <View style={{ alignItems: 'center' }}>
      {/* Cap */}
      <View style={styles.btlCap} />

      {/* Neck — slightly wider at bottom for taper start */}
      <View style={styles.btlNeck}>
        <View style={styles.btlNeckInner} />
      </View>

      {/* Shoulder taper — connects neck to body smoothly */}
      <View style={styles.btlShoulder} />

      {/* Body */}
      <View style={styles.btlBody}>
        <BeerFill
          fillLevel={Math.min(fillLevel * 1.2, 1)}
          tiltDeg={tiltDeg}
          containerWidth={BTL_BODY_W - 6}
          containerHeight={innerH}
        />
        <FoamHead
          fillLevel={Math.min(fillLevel * 1.2, 1)}
          tiltDeg={tiltDeg}
          containerWidth={BTL_BODY_W - 6}
          containerHeight={innerH}
        />
      </View>
    </View>
  );
};
```
